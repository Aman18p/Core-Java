What is StringBuilder in Java?
-StringBuilder is a mutable class in java.lang package used to modify strings without creating new objects.
-Similar to StringBuffer, but not synchronized, so it is faster and not thread-safe.
-To overcome the problem of slow performance of StringBuffer methods, Java introduced StringBuilder concept in JDK 1.5 version and creates all the methods of Stringbuilder as non-synchronized which increases the methods performance.

When to Use StringBuilder
When you need to modify strings frequently (like in loops).

In single-threaded environments where synchronization is not required.
